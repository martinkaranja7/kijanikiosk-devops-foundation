#How Flow, Feedback, and Learning apply to KijaniKiosk Devops

1.For Flow
 Application of branches use of branches such as develop and features ensures that during devlopment we don`t disrupt production environment.

2.For Feedback
When someone makes changes to code  a Pull Request has to be initiated into develop, hence team members review code, provide feedback, and catch mistakes early.

3 Learning
 From the feedback when an issue is discovered there is no blaming rather analysises are done to improve systems rather than blame someone.
